WARENA provides the **computing infrastructure** for IKAI MIRROR+ experiments:

## 4. What WARENA must supply for Phase 1 (conventional mirror)

Minimum infrastructure research targets — not a shopping list claim:

1. Bootable reproducible workstation profile (external SSD qualification path already documented separately).
2. Camera and display device access under explicit user permissions.
3. Local disk for application data, calibration and consent records.
4. Network default-deny for application data; optional explicit outbound.
5. Backup/restore runbook for mirror application data directories.
6. Development shell: Guile, toolchain, OpenCV/MediaPipe candidates evaluated under pinned Guix revisions.

Aerial optics (AIRR/MiTAI) are **not** Phase 1 infrastructure prerequisites.

## 5. Privacy infrastructure requirements

WARENA-side expectations for any IKAI deployment experiment:

- Camera and mic indicators; no silent capture services
- Per-app data directories; no automatic cross-app merging of beauty and body records
- Documented retention and secure deletion procedures
- Offline mode as first-class
