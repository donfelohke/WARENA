# WARENA — Foundations

## Principles

1. **Freedom Is a System** — capability over dependency theatre  
2. **Local-first when it matters** — offline-capable where connectivity fails  
3. **Reproducible preference** — document so another person can repeat  
4. **Human remains author** — automation assists; operators decide  
5. **Honest maturity** — LIVE vs PROTOTYPE vs RESEARCH  

## Architecture assumptions

- Client environments vary (Windows residual, mixed hardware, constrained bandwidth)  
- Prefer free/open tooling where it reduces lock-in  
- Security is process + updates + least privilege — not a logo  

## Decision notes

- RDE / Guix / dwl-guile explorations are **research or lab** unless a specific host is documented as LIVE with recovery steps  
- Public Digital services are scoped **per engagement**
