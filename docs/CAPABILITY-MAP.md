# WARENA capability map

**Status:** Capability orientation · not a live service menu  
**Commercial path:** NAKEBUSEN only  
**Transaction boundary:** **ONLY NAKEBUSEN TRANSACTS.**

This map describes areas in which WARENA has relevant technical direction or documented interest. It does not establish that every service is currently available, that a specific configuration is supported, or that a project has been accepted.

## Potential engagement areas

The following may be considered for a scoped NAKEBUSEN Digital enquiry, subject to current capacity, technical feasibility, hardware/software compatibility and explicit agreement:

- GNU/Linux installation, administration and troubleshooting.
- Computer diagnostics, recovery and system maintenance.
- Network configuration, Wi-Fi and LAN troubleshooting.
- Router, server and small-office infrastructure planning or support.
- Laboratory, classroom and cybercafé systems.
- Offline-capable and local-first environments where appropriate.
- Reproducible development environment design and setup.

**No automatic service commitment:** before accepting work, confirm the problem, device and software versions, access requirements, data-handling constraints, deliverables, price, schedule, support boundary and recovery plan. Do not promise repair, compatibility, uptime or security outcomes without evidence.

## Research and experimental work — not products

- RDE / Guix-oriented workstation architecture.
- dwl-guile and Guile-native desktop experiments.
- Reproducible operating-system images for specific hardware.
- Real-time bidirectional I/O, camera/display pipelines and related integration research.
- Human-governed computing and agent authority models.

A research note, design, repository or proposed benchmark is not proof of a working deployment. Label each artefact by maturity and attach source revisions, test conditions, results and limitations before making implementation claims.

## Explicit domain boundaries

- **NAKEBUSEN:** loc care and the sole customer-facing commercial and transaction interface.
- **WARENA:** technical capability and systems engineering; not a separate checkout or booking brand.
- **IKAI:** reflective-computing research; not a released WARENA or NAKEBUSEN product.
- **GENJE:** creative and embodied practice; not a software SKU.
- **FELOH Corpus:** shared canon, governance, evidence and provenance.

## Engagement path

1. Enquiry is received through NAKEBUSEN.
2. Scope, feasibility, availability, risks and data-handling requirements are reviewed.
3. Deliverables, price, timing and support limits are agreed before work begins.
4. Work is performed only within the agreed scope.
5. Handover records versions, configuration, known limitations, recovery steps and any follow-up terms.

An enquiry is not an accepted project. A public capability description is not a guarantee of immediate availability.
