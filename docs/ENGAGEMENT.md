# Engagement model

1. **Enquire** via NAKEBUSEN (WhatsApp / email / site).  
2. **Describe** current setup, problem, outcome, constraints.  
3. **Agree** scope, deliverables, price, timeline, support.  
4. **Execute** with explicit change control.  
5. **Hand over** with enough documentation for maintenance.

Enquiry ≠ accepted project. No work starts on assumed scope.
